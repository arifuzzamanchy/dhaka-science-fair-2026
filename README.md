
# Dhaka Science Fair 2026

## About Project
This is an HTML-based website for Dhaka Science Fair 2026.

The website provides information about the science fair, subjects, event schedule, video, and student registration.

## Features
- Header and Navigation Menu
- About Science Fair Section
- Science Subject Lists
- Event Schedule Table
- YouTube Video
- Registration Form with Validation
- Footer and Contact Information

## Technologies Used
- HTML5

## Project Structure
- index.html
- science-fair.jpg
- README.md

## How to Run
1. Download or clone this repository.
2. Open index.html in your browser.
